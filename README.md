# English с Никой

Android-приложение для занятий английским и математикой дома. Главная героиня и голосовая помощница — **Ника**, персонаж, которого придумала Вероника (векторный рисунок: `art/nika.svg`, анимация: `app/.../ui/Nika.kt`).

Ника по умолчанию живая объёмная: векторная, со светотенью как у 3D (градиенты на лице, глянец волос и глаз, «цилиндрический» костюм, тени), и двигается всем телом — руки, ноги, моргание, рот в такт речи, прыжки, танец. Губы — по рисунку Вероники: верхняя «галочкой», нижняя полукругом. В настройках можно включить неподвижные 3D-картинки из OpenArt (8 поз в обычном наряде и 8 — в строгом).

Видео-заставка «Ника ведёт в мир учёбы» (сделано в Gemini по начальному кадру из OpenArt, `res/raw/nika_intro.mp4`, 1,2 МБ) — на экране выбора предмета: в первый раз играет само, дальше по кнопке ▶.

«Сколько говорит Ника» — кнопка вверху экранов: 🔊 всё, 🔉 меньше слов (только читает задания — без приветствий, похвалы и замечаний), 🔇 молчит (только текст, звук — по кнопкам 🔊). С младшей Ника говорит всегда.

Дизайн — «стекло»: полупрозрачные кнопки с бликами поверх неба с переливами. Небо и комиксы с Никой нарисованы в OpenArt по референсу персонажа (`app/src/main/res/drawable-nodpi/`).

Всё хранится на телефоне, свой сервер не нужен. Интернет нужен только нейросети, дневнику МЭШ и (по желанию) голосу Yandex.

## Что умеет

**Режим школьницы**
- 📸 Сфотографировать страницу учебника. Текст распознаётся прямо на телефоне (ML Kit), нейросеть собирает урок: слова с транскрипцией и картинкой, правило простыми словами, фразы. Камера своя, внутри приложения: системную камеру родительский контроль ограничивает по времени, а эта работает, пока открыта Ника.
- ▶️ Тренировка: знакомство со словом, выбор перевода на слух, «как это по-английски», правописание по буквам, произношение в микрофон, сборка предложения на слух.
- 🧩 Упражнения на правила и построение предложений: вставить слово, выбрать правильное предложение (с типичными ошибками), собрать предложение по-русски с лишними словами-ловушками; после ответа — объяснение. Если задание нельзя решить (нейросеть ошиблась) — «🚩 В задании ошибка»: оно уберётся навсегда и не засчитается как ошибка.
- 📘 «Правила»: 18 тем 2–4 класса (to be, have got, can, Present Simple, there is/are, Present Continuous, Past Simple, сравнения…) с правилом, примерами и упражнениями без интернета; «Ещё задания от Ники» — новые упражнения от нейросети.
- Урок по фото учитывает пройденное: нейросеть делает упражнения на грамматику страницы и отмечает связанные темы прошлых лет — они повторяются в тренировке урока.
- 🖼 «Комиксы с Никой»: 11 комиксов по темам правил (6 кадров), Ника читает их по-английски с переводом и объясняет, чему учит комикс (слова правила подсвечены, перевод можно спрятать), комикс можно увеличить на весь экран; оттуда — тренировка темы.
- 🔁 Интервальное повторение (система Лейтнера) и для слов, и для правил: через 1, 2, 4, 7, 14, 30 дней, ошибочное — на следующий день.
- 💬 Разговор с Никой голосом (русский или английский микрофон) или текстом. Ника знает текущие слова и что задали в школе.
- 🎒 Готовые темы без интернета: 12 наборов слов с картинками.
- 🏫 Дневник МЭШ: расписание, оценки, средние баллы и домашка. Если в задании по английскому есть «стр. 45» — одна кнопка «Сфоткать страницу 45».

**Математика** (после выбора профиля — «Английский» или «Математика»; строгий стиль: тетрадь в клетку, Ника в пиджаке и очках)
- 📸 Фото страницы учебника Моро («Школа России») → нейросеть разбирает правило и примеры страницы и придумывает задачи. Всё, что можно посчитать, приложение пересчитывает само и отбрасывает задачи с ошибками в ответах.
- 📘 Программа 3–4 класса без интернета: 19 тем (таблица умножения, внетабличное умножение и деление, деление с остатком, порядок действий, письменное сложение и вычитание, величины, периметр и площадь, доли, уравнения, задачи на цену и на движение, многозначные числа, умножение и деление многозначных, сравнение). Задачи генерируются заново каждый раз.
- ⌨️ Ответ цифрами на экранной клавиатуре (есть кнопка «ост.»), вторая попытка, после ошибки — правильный ответ и решение по шагам вслух.
- 🔁 Повторение тем по интервалам, разминка из пройденного; «🚩 В задаче ошибка» для задач нейросети; Ника-помощница по математике; оценки и домашка по математике из МЭШ.

**Режим малышки** (без чтения, всё голосом)
- 🦜 «Повторяй за мной»: Ника называет картинку, малышка повторяет в микрофон и получает звёздочки.
- 🔍 «Найди картинку»: «Где dog?» — нажать на нужную картинку.
- ⭐ Слова старшей сестры тоже попадают в игры.
- 🔢 Счёт до 20: «Сколько?» (можно считать пальчиком — Ника называет числа), «Найди число», «Где больше?», «Сложи картинки».
- 🔤 Буквы и чтение по методике букваря Н. С. Жуковой: 33 буквы по порядку букваря (А, У, О, М, С, Х, Р, Ш, Ы, Л, Н, К, Т, И, …), гласные красные, согласные синие. Урок буквы: знакомство (как звучит и на что похожа), обвести пальчиком, найти букву, картинка на эту букву, «паровозик» — согласная бежит к гласной и получается слог, найти слог, прочитать слово по слогам и найти к нему картинку. Слова — только из уже пройденных букв. Следующая буква открывается после урока; «Повторяем» — всё вперемешку. Картинки к словам — пиктограммы [ARASAAC](https://arasaac.org) (CC BY-NC-SA 4.0: Pictographic symbols are the property of the Government of Aragón and have been created by Sergio Palao for ARASAAC), только для некоммерческого использования; скачиваются workflow «Картинки ARASAAC», в приложение собираются `tools/build_abc_pictures.py`.

## Установка
1. Откройте [Releases](../../releases) на телефоне, скачайте последний `english-nika-*.apk` и откройте его.
2. При первом запуске введите имена детей.
3. ⚙️ «Для родителей» (решить пример) → подключите нейросеть.

## Нейросеть (работает в РФ без VPN)

**GigaChat (по умолчанию)**
1. [developers.sber.ru](https://developers.sber.ru/studio) → проект GigaChat API → «Настройки API» → «Получить ключ» → скопируйте *Authorization Key*.
2. В настройках приложения вставьте ключ, тип доступа — «Физлицо (PERS)».
3. «Проверить связь».

Сертификат НУЦ Минцифры, нужный GigaChat, уже встроен в приложение (`core/src/main/resources/.../russian_trusted_ca.pem`, скачан с gu-st.ru; SHA-256 корневого — `D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31`). Ему доверяет только HTTP-клиент GigaChat — остальные соединения телефона и приложения он не затрагивает. Если Минцифры выпустит новый сертификат, его можно загрузить в настройках.

**YandexGPT** — API-ключ сервисного аккаунта и ID каталога из Yandex Cloud.

## Голос Ники
- **Голос телефона** (по умолчанию, бесплатно, без интернета): ⚙️ → Голос → синтезатор (лучше «Синтезатор речи Google»), английский и русский голос, высота каждого, «Послушать вместе».
- **Yandex SpeechKit** (платно, нужен Yandex Cloud с картой): один женский голос читает всю фразу — и русские, и английские слова (по умолчанию Даша, дружелюбная, скорость 1.05, высота +29; есть Маша, Лера, Марина, Джейн). Голоса LiveTTS живее, но английский не читают, поэтому в английском не используются; для математики по умолчанию — живой голос LiveTTS (София), его можно сменить в настройках. Если он не ответит, математику читает обычный голос Ники. Английских женских голосов у Яндекса нет: единственный английский голос, john, — мужской. Поэтому английские слова читает русский голос. Как это звучит, лучше проверить кнопкой «Послушать вместе». Настройка: сервисный аккаунт с ролями `ai.speechkit-tts.user` (и `ai.speechkit-stt.user` для распознавания) → API-ключ и ID каталога в настройках приложения. Озвученные фразы кэшируются на телефоне, повторно за них не платите.

## Дневник МЭШ
Вход через официальную страницу mos.ru внутри приложения: пароль вводится на сайте, приложение его не видит. После входа приложение берёт токен `aupd_token` и обращается к мобильному API school.mos.ru. API неофициальный, протокол взят из [OctoDiary](https://github.com/OctoDiary/octodiary-py) (MIT). Если МЭШ поменяет API, раздел может перестать работать — остальное приложение от него не зависит.

Если вход на телефоне не работает, ключ передаётся с компьютера по QR-коду: откройте на компьютере `tools/nika-keys.html` (работает без интернета, ключ никуда не отправляется), вставьте `aupd_token` с school.mos.ru и в приложении нажмите «📷 Сканировать QR с компьютера». Там же можно передать ключи GigaChat и Yandex Cloud.

## Сборка
APK собирает GitHub Actions (`.github/workflows/android.yml`): тесты ядра → `assembleRelease` → релиз с APK.

Чтобы новые версии ставились **поверх** старых и не стирали прогресс, APK нужно подписывать одним и тем же ключом. Добавьте в Settings → Secrets and variables → Actions:

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | файл ключа в base64 |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `nika` |
| `KEY_PASSWORD` | пароль ключа (обычно тот же) |

Без секретов APK подписывается временным ключом. Тогда перед обновлением сохраните резервную копию: «Настройки → Данные».

Локально: Android Studio, JDK 17 → `./gradlew :app:assembleDebug`.

## Устройство
- `core/` — чистый Kotlin, покрыт тестами: модели, интервальное повторение, проверка ответов, генерация заданий, математика (`core/.../math`: темы, генераторы задач, вычислитель для проверки задач нейросети, озвучка формул), клиенты GigaChat / YandexGPT / SpeechKit / МЭШ, промпты.
- `app/` — Jetpack Compose: экраны, Ника, голос (Android TTS / SpeechKit), распознавание речи, камера + ML Kit.
