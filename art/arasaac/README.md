# Картинки ARASAAC

Пиктограммы для букваря младшей. Источник: https://arasaac.org

Лицензия CC BY-NC-SA 4.0 — только некоммерческое использование, с указанием авторства:
Pictographic symbols are the property of the Government of Aragón and have been created by Sergio Palao for ARASAAC.

- `png/` — первая найденная картинка для каждого слова (`tools/fetch_pictures.py`), `sheet_*.png` — листы для проверки.
- `alt/` — варианты для слов, где первая не подошла, `alt_*.png` — листы с номерами.
- Выбор и сборка в приложение: `tools/build_abc_pictures.py` (словарь `CHOSEN`).
