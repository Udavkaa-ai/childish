Название: English с Никой

Android-приложение для занятий английским дома: фото страницы учебника превращается в урок со словами, правилами и упражнениями, помогает голосовая помощница Ника.

Стек: Kotlin, Jetpack Compose, ML Kit (OCR на телефоне), GigaChat или YandexGPT, Yandex SpeechKit и Android TTS, OkHttp, kotlinx.serialization, сборка APK в GitHub Actions.

Сейчас в фокусе: стеклянный дизайн с живым фоном, картинки с Никой из OpenArt, кнопка «В задании ошибка» и строгий промпт для упражнений. Недавно: 18 тем грамматики 2–4 класса, аватарки детей, дневник МЭШ.

Особенности: всё хранится на телефоне, сервера нет; логика в чистом Kotlin-модуле core с тестами; Ника нарисована кодом на Compose Canvas со сгибаемыми руками и ногами; интервальное повторение по Лейтнеру для слов и правил; режим без чтения для младшей сестры.
