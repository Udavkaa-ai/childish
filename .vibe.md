Название: English с Никой

Android-приложение для семейных занятий английским: фото страницы учебника превращается в урок со словами, правилами и упражнениями, а помогает девочкам голосовая помощница Ника — персонаж, которого придумала старшая дочь.

Стек: Kotlin, Jetpack Compose (Material3), ML Kit для распознавания текста на телефоне, GigaChat или YandexGPT для генерации уроков, Yandex SpeechKit и Android TTS для голоса, OkHttp и kotlinx.serialization. Сборка подписанного APK и публикация релиза — GitHub Actions.

Сейчас в фокусе: стеклянный дизайн с живым фоном, небо и комикс с Никой, нарисованные в OpenArt по референсу персонажа, кнопка «В задании ошибка» и более строгий промпт, чтобы нейросеть не путала русскую и английскую фразу. Недавно добавлены 18 тем грамматики 2–4 класса, фото детей на аватарках и дневник МЭШ (оценки и домашка).

Особенности: всё хранится на телефоне, своего сервера нет; логика вынесена в чистый Kotlin-модуль core с тестами; Ника нарисована кодом на Compose Canvas со сгибаемыми руками и ногами; интервальное повторение по Лейтнеру и для слов, и для правил; есть простой режим без чтения для пятилетней сестры; сертификат НУЦ Минцифры встроен только в HTTP-клиент GigaChat.
